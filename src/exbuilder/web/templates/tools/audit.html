API

For scripts and other tools. Sign in with your user name and the API token from your account page (HTTP Basic auth). Add ?client= with a client's id or name when you are in more than one, and &space=lab for the Lab space. Read-only people get passwords and keys hidden, like on the web pages. Every change made over the API lands in the audit log.

CallWhat it doesRole
GET /api/v1/clientsYour clients and your role in eachany
GET /api/v1/projectsThe saved projects of a client and spaceread-only
GET /api/v1/projects/<id>One project (the builder's JSON)read-only
GET /api/v1/projects/<id>/configIts config as text; ?format=hierarchy for Junos in bracesread-only
PUT /api/v1/projects/<name>Create or replace a project by nameconfigurator
GET /api/v1/backupsConfig backups; ?host= for one switch, ?latest=1 for the newest of eachread-only
GET /api/v1/backups/<id>One backup; ?format=text for the config aloneread-only
GET /api/v1/auditThe audit log, same filters as above (user, client, kind, since, until, q, limit)admin
POST /api/generateBuild a config from a project sent as JSON, without saving itany

Examples

curl -u {{ g.user['username'] }}:YOUR_TOKEN '{{ base }}/api/v1/projects?client={{ (mine[0].name if mine else 'Default')|urlencode }}'
