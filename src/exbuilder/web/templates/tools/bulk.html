Bulk build

Build one switch the way you like it and save it as a project. Use it here as the template, add a spreadsheet with one line per switch, and you get a config for every switch at once. Save them all as projects or download them as a zip.

1. Template

How the spreadsheet fills the template
  • Usual columns: {% for k in well_known %}{{ k }}{{ ", " if not loop.last }}{% endfor %}. Only hostname is required. ip, gateway and serial_number work too.
  • Placeholders: write {{ '{{' }}site{{ '}}' }} anywhere in the template (an IRB address such as 10.{{ '{{' }}site{{ '}}' }}.20.1/24, a description, a banner) and add a site column.
  • Any field by path: a column called system.banner, vlans.MGMT.irb (the VLAN named MGMT) or ports.0.description (the first port group) sets that field.
  • Commas, semicolons or tabs between columns. Lines starting with # are skipped. Up to {{ max_rows }} switches.
