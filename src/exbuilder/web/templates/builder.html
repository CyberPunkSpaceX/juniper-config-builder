Root account

Junos won't commit without a root password. Passwords are turned into SHA-512 hashes as soon as the config is generated, so plain text is never saved in a project.

Local users

super-user = full access, operator = view and clear, read-only = view only.

VLANs

Give a VLAN an IRB address to route it (layer 3). Several addresses can be comma-separated, including IPv6. DHCP relay forwards requests to the server on the Routing tab. Snooping, DAI and IP source guard protect against rogue DHCP servers and spoofing.

Port groups

Each group gives the same settings to a set of ports. Write ports like ge-0/0/0-23, ge-0/0/30. Modes: access (one VLAN, plus an optional voice VLAN), trunk (several tagged VLANs, optional untagged native VLAN), routed (layer 3 port with its own IP), disabled.

Link aggregation (LAG / ae)

Bundle ports into one logical link with LACP. The other end must be set up the same way. Usually a trunk to a core switch, firewall or server.

Routing identity

The loopback (lo0) is a stable address for OSPF, BGP and EVPN-VXLAN. The router ID defaults to the loopback.

Static routes

Use 0.0.0.0/0 for the default route. The next hop can be an IP address, discard or reject.

DHCP relay

Relay is turned on per VLAN on the VLANs tab.

OSPF

List the interfaces that run OSPF in each area, like xe-0/2/0, irb.20, lo0 (unit .0 is added when you leave it out). Passive interfaces are advertised but form no neighbours: use it for user VLANs and the loopback. Point-to-point is right for a routed link between two switches.

Areas

BGP

Set the local AS on the Routing tab. Neighbors: one per line as IP [peer AS] [description], for example 10.1.1.0 64512 ISP router. Import and export take policy names from the Policies tab. Without an export policy, external BGP advertises nothing.

Communities

Policy statements

Each row is one term. Terms with the same policy name form one policy and are checked top to bottom; use ↑ to reorder. A term without any "from" matches every route, so a last term with reject drops whatever the earlier terms didn't accept.

EVPN-VXLAN

Stretches VLANs over a routed (layer 3) network. Each switch needs a loopback and AS (Routing tab) and an underlay that reaches the other loopbacks (OSPF or BGP on the OSPF & BGP tab, MTU 9216 on fabric links). Then give VLANs a VNI on the VLANs tab. Runs on the EX4100, EX4400 and EX4300-48MP, with a feature license.

On the VLANs tab: VNI stretches the VLAN, anycast gateway is the shared default gateway all leaves answer for (each leaf keeps its own IRB address in the same subnet), and VRF puts the VLAN's IRB in a tenant VRF. On the LAGs tab, an ESI and LACP system ID make a LAG span two switches (ESI-LAG multihoming).

Tenant VRFs (layer 3 routing between leaves)

Routes between VLANs in the same VRF across the fabric (EVPN type-5). The ID becomes the route distinguisher and loopback unit; the L3 VNI must be the same on every leaf.
